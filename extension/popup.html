The extension talks only to the URL above. The API key is created in the OmniRoute dashboard (Settings → API Keys) or via omniroute tokens create --scope admin. An admin-scope key is pre-filled (see config.js).
While on, the extension re-grabs all signed-in sessions on the schedule above, and checks every 30 minutes for connections OmniRoute reports as expired (re-pushing just those). Runs only while the browser is open.
